Version 0.23.0 - Overhaul of The Basics
Description
The script was broken. What came after was worse. An original Terraria horror mod set in the aftermath of The Broken Script's events.
Built from the ground up, with a new world, a new story and the same dread.

Features
Entities: Execute, Follow, Obliteration, Observe, Possessor, SiluetR2, SubAnomalyOne
Random Events and Structures
Corrupted Moon and Corrupted Day events
A new dimension, one of many to come...
A configuration system for all non-mandatory gameplay functionality
Multiplayer compatible
