[h3] Version 0.23.0 - [i]Overhaul of The Basics[/i] [/h3]
[h3] Description [/h3]
The script was broken. What came after was worse. An original Terraria horror mod set in the aftermath of [b]The Broken Script's[/b] events.
Built from the ground up, with a new world, a new story and the same dread.

[h3] Features [/h3]
[list]
[*] [i] Entities: Execute, Follow, Obliteration, Observe, Possessor, SiluetR2, SubAnomalyOne [/i]
[*] [i] Random Events and Structures [/i]
[*] [i] Corrupted Moon and Corrupted Day events [/i]
[*] [i] A new dimension, one of many to come... [/i]
[*] [i] A configuration system for all non-mandatory gameplay functionality [/i]
[*] [i] [b] Multiplayer compatible [/b][/i]
[/list]
